# 🚇 부산 하차 알리미

부산 지하철에서 영상을 보거나 딴짓을 하다가 **내릴 역을 놓치지 않도록** 알려주는 웹앱(PWA)입니다.
설치 없이 폰 브라우저에서 바로 쓰고, **홈 화면에 추가하면 앱처럼** 동작합니다.

## ✨ 기능

- **3가지 알림 방식**
  - ⏱️ **시간 예측 (기본·추천)** — 출발/도착역만 고르면 남은 역 수 × 역당 평균 소요시간으로
    도착 예정시각을 계산해 자동 카운트다운. **지하 구간에서도 100% 동작**하고 GPS·데이터가 필요 없습니다.
  - 📍 **GPS 자동** — 현재 위치를 추적해 목적지에 가까워지면 알림. 지상 구간·주요역에서 강력합니다.
  - 👆 **수동 탭** — 역에 정차할 때마다 버튼을 눌러 카운트다운. 가장 확실합니다.
- **놓치지 않는 알림** — 전체 화면 경고 + 반복 비프음 + 진동
- **몇 정거장 전에 알릴지 선택** (도착역 / 1·2·3 정거장 전)
- **화면 꺼짐 방지**(Wake Lock)로 영상 보는 중에도 알림 유지
- **오프라인 지원** — 한 번 열면 지하에서 네트워크가 끊겨도 동작
- 1~4호선 전 역(총 115역) 지원

## 📱 폰에 "앱처럼" 설치하기

1. 배포된 주소(GitHub Pages URL)를 폰 브라우저로 엽니다.
2. **iPhone(Safari)**: 공유 → **홈 화면에 추가**
   **Android(Chrome)**: 메뉴(⋮) → **홈 화면에 추가 / 앱 설치**
3. 홈 화면 아이콘으로 실행하면 주소창 없이 전체 화면 앱으로 동작합니다.

## 🚀 배포 (GitHub Pages)

이 저장소에는 자동 배포 워크플로우(`.github/workflows/deploy-pages.yml`)가 포함되어 있습니다.

1. GitHub 저장소 **Settings → Pages → Build and deployment → Source** 를 **GitHub Actions** 로 설정합니다.
2. `docs/` 변경사항을 기본 브랜치(master/main)에 푸시하면 자동으로 배포됩니다.
3. 배포 후 주소는 보통 `https://<사용자명>.github.io/<저장소명>/` 입니다.

> 로컬에서 바로 확인하려면 `docs/` 폴더에서 `python3 -m http.server` 후
> `http://localhost:8000` 접속. (Service Worker/설치 기능은 http/https에서만 동작)

## 🗺️ 역 데이터 보완

`docs/data.js`에 노선별 역 순서·좌표가 들어 있습니다.

- **역 순서 / 평균 소요시간** → 시간·수동 모드의 핵심. 실제 운행 순서 기준입니다.
- **좌표(coord)** → GPS 모드용. 주요역 위주의 근사값이라 더 정확히 맞추고 싶다면
  공공데이터포털의 **[국가철도공단_부산1호선 역위치](https://www.data.go.kr/data/15041165/fileData.do)**
  또는 **[전국도시철도역사정보 표준데이터](https://www.data.go.kr/data/15013205/standard.do)** 의
  위·경도로 교체하면 됩니다. 좌표 형식은 `[위도, 경도]` 입니다.

## 🧩 구조

```
docs/
├─ index.html            화면 마크업
├─ styles.css            스타일 (다크, 모바일 우선)
├─ app.js                로직 (3가지 모드, 알람/진동/Wake Lock)
├─ data.js               1~4호선 역 데이터
├─ manifest.webmanifest  PWA 설치 정보
├─ sw.js                 오프라인 캐시 (Service Worker)
└─ icon.svg              앱 아이콘
```

의존성 없는 순수 HTML/CSS/JS라 빌드 과정이 없습니다.
